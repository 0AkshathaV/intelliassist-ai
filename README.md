# IntelliAssist AI: Smart Document AI Assistant

Upload PDF, TXT or DOCX files and ask questions about them. Every answer shows the exact passages it came from, with page numbers and a confidence score, and the app declines to answer when the information is not in your documents.

## Features
| Feature from the project brief | Implementation |
|---|---|
| Document upload (PDF/TXT/DOCX) | pypdf and python-docx, several files at once |
| AI chatbot with RAG | LangChain splitter and FAISS, answers generated by Gemini |
| Semantic search using embeddings | all-MiniLM-L6-v2 (BERT family) plus TF-IDF, fused with Reciprocal Rank Fusion |
| Text summarisation | Short, medium and detailed summaries |
| Sentiment and intent analysis | Three-class sentiment model (positive, neutral, negative) and intent detection |
| Source citation display | Highlighted passages with file, page and match score |
| Conversation history | Follow-up questions understood; chat can be exported as JSON |
| Streamlit web interface | Chat, Summarize, Quiz and Insights tabs |

**Extras:** quiz generator, multilingual mode (Hindi, Kannada, Tamil and more), "not found" guard against hallucination, confidence score, optional cross-encoder re-ranking, per-file search, and an offline mode that works without an API key.

## Architecture
```
Upload -> extract text (pypdf / python-docx) -> chunk (LangChain, 700 chars, 120 overlap)
       -> embed (MiniLM) + TF-IDF index -> FAISS vector store

Question -> history-aware rewrite -> dense search + TF-IDF search
         -> Reciprocal Rank Fusion -> top passages -> Gemini
         -> answer + citations + confidence
```

## Evaluation
30 questions over 3 test documents (18 passages). Details in `evaluate.py` and `eval_set.json`.

| Method | Recall@1 | Recall@5 | MRR | Avg latency (ms) |
|---|---|---|---|---|
| TF-IDF | 0.933 | 1.000 | 0.961 | 31.3 |
| Dense (embeddings) | 0.900 | 1.000 | 0.939 | 33.6 |
| **Hybrid** | **1.000** | 1.000 | **1.000** | 26.7 |
| Hybrid + re-rank | 1.000 | 1.000 | 1.000 | 1389.2 |

Hybrid search ranked the correct passage first for all 30 questions. The re-ranker added no accuracy on this test and was about 52 times slower, so it is optional and off by default. The test documents were written for this evaluation, so the results describe a controlled benchmark, not real-world performance.

## Tech stack
Streamlit, Python, LangChain, Hugging Face (sentence-transformers, RoBERTa sentiment, cross-encoder), FAISS, scikit-learn TF-IDF, Gemini API.

## Run locally (Windows)
```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
1. Get a free Gemini API key at https://aistudio.google.com/apikey.
2. Double-click `setup_key.bat` and paste the key once. It is saved to `.streamlit/secrets.toml`, which is excluded from Git.
3. Double-click `run_app.bat`, or run `streamlit run app.py`, and open http://localhost:8501.

On macOS or Linux: `source venv/bin/activate`, then `export GEMINI_API_KEY=your_key` and `streamlit run app.py`. The app also works without a key, using extractive answers.

**Never commit your API key.**

## Evaluate
```
python evaluate.py
```
Results are saved to `evaluation_results.csv`.

## Deploy (Streamlit Community Cloud)
Push to GitHub, open https://share.streamlit.io, create a new app that points to `app.py`, and add `GEMINI_API_KEY = "..."` under Settings, then Secrets.

## Limitations
- Evaluated on a small, self-written document set.
- Scanned PDFs need OCR, which is not included.
- The re-ranker is English only.
- Answer generation depends on the Gemini API, whose availability varies.
